# ForecastLab 多臂对照实验报告

**日期**：2026-10-04　**套件**：`eval/suites/forecastlab-v1.json`（24 案例）　**数据**：`experiment/v1-2026-10-04/results/v1-2026-10-04.json`（复现命令输出到 `data/eval/`）

## 1. 引言

ForecastLab 是一条"证据优先"的事件预测流程：把问题拆成问题定义、证据整理、世界状态、主体推演、审查、汇总六个阶段，最终输出带引用、标注未校准的主观概率。流程可以运行，但仓库此前没有可复现的量化结果，无法回答一个基本问题：多阶段流程相对"直接把问题交给大模型回答一次"是否更好，代价是什么。

本实验用同一批历史问题、同一份冻结证据包，比较四个对照臂，量化三个差异来源：多阶段流程本身、证据包、模型自身知识。实验规模为 24 个案例、4 个类别，单轮运行。

研究问题：

| 编号 | 问题 | 观测指标 |
| --- | --- | --- |
| Q1 | 完整流程是否比单次调用更准 | Brier、BSS、覆盖率 |
| Q2 | 证据包的边际贡献 | 有证据与无证据单 Agent 的差值 |
| Q3 | 多阶段流程的额外代价 | 模型调用次数、token、耗时 |
| Q4 | 系统在哪里失败 | 覆盖率、分类分层结果 |

## 2. 方法

### 2.1 实验设计

四个对照臂回答同一批问题、使用同一份证据包，只有流程不同：

| 臂 | 定义 | 模型调用 |
| --- | --- | --- |
| A 完整框架 | 六阶段流程，含审查与汇总 | 每案例最多 18 次 |
| B 单 Agent + 同证据 | 一次调用，输入问题与相同证据包 | 1 次 |
| C 单 Agent 无证据 | 一次调用，只输入问题 | 1 次 |
| D 恒定 50% | 公式计算，不调用模型 | 0 次 |

判定一律采用**实际动作口径**：开售、出货、客户部署、正式发布到 npm、实际比赛结果、官方文本实际通过、会议实际举行才算数；发布会、新闻稿、路线图承诺不作为结算依据。信息截至日之前尚未发生的资料不得进入证据包。

### 2.2 评价指标

记实际结果 `y ∈ {0,1}`，预测"是"的概率为 `p`。

| 指标 | 定义 | 读法 |
| --- | --- | --- |
| Brier | `mean((p − y)²)` | 越小越好，0.25 等价于恒定 50% |
| 覆盖率 | 给出概率的案例数 / 已结算案例数 | 与 Brier 同时报告 |
| 弃权回退 Brier | 弃权按 0.5 计入的 Brier | 防止"少答保分" |
| BSS vs 0.5 | `1 − Brier / 0.25` | 0 等于恒定 50% |
| BSS vs 基准率 | `1 − Brier / Brier(样本基准率)` | 参考线完美时返回 `null` |

参考线与被测臂在同一批已答样本上计算。BSS 的参考误差为 0 时记 `null`，不补零。

### 2.3 运行流程

1. 冻结输入：确定套件、证据包、模型、提示词版本与预算。
2. 校验套件：`--dry-run` 检查案例数、类别分布、模型可用性与调用上限，不产生模型调用。
3. 全量运行：对 24 个案例依次执行 A/B/C 三臂，逐案例写出概率、代价与错误。
4. 计分：按臂汇总 Brier、覆盖率、弃权回退 Brier 与两套 BSS，并按类别分层。

### 4.5 分析

第一，完整框架的主要短板是覆盖率。它在 24 个案例中只对 10 个给出概率，拒答集中在需要外部事实核实的案例（任务状态、赛事结果、官方文本）。弃权回退 Brier 0.2470 表明，减少作答没有带来实质分数优势。

第二，证据是有效的。单 Agent 从无证据到有证据，Brier 由 0.2582 降到 0.1791，BSS 由 −0.033 升到 +0.284；这是本轮最干净的一组对照。

第三，无证据臂接近随机。Brier 0.2582、BSS −0.033，说明模型自身知识对本批历史问题基本没有可用信号。

第四，财经层的三臂分数接近，且无证据臂最低，但该层 5 个案例中 4 个结果为"是"（基准率 0.8），偏高的常量猜测占优，不能据此判断无证据更强。

第五，完整框架与第 7 章 2 案例试点相比，覆盖率问题被放大。试点时三臂均给出概率；24 案例时完整框架覆盖率降至 41.7%。

### 4.6 局限

本轮只运行一次，未做重复性与 pass^k；温度沿用接口默认值，跨轮波动无法归因；未做引用支持率的人工标注；C03–C20 部分证据缺少明确发布日；C06、C07、C10、C11、C12、C14、C16、C18、C20、C24 等使用次级来源结算；全部案例为历史回看，存在回看偏差；财经层结果偏"是"，分层结论不稳健。

## 5. 结论

24 案例首轮实验得到三条结论：完整框架当前的主要问题是覆盖率，仅对 41.7% 的案例给出概率；单 Agent + 同证据显著优于恒定 50% 参考线（Brier 0.1791，BSS +0.284）；无证据臂接近随机（Brier 0.2582），支持成绩主要来自证据而非模型记忆。由于单轮运行、温度未固定、证据包存在日期与次级来源缺口，以上应视为首轮正式结果；对外定稿前需补重复运行、人工核查与证据包补强。

### 6.5 分析

合并 问题分析与证据评估 后，完整框架的弃权从 14/24 增加到 20/24，只有 4 个案例给出概率；弃权回退 Brier 从 0.2470 升到 0.2641，相对 50% 参考线由略优转为明显落后（BSS 从 +0.029 降到 −0.337）。单 Agent 两臂变化很小，单 Agent + 同证据反而从 0.1791 小幅改善到 0.1736。

完整框架退化最明显的是科技层（覆盖率 1/7，Brier 0.6724）和公共层（覆盖率 0/6）。问题分析与证据评估 引入了问题确认、前提处理、证据契约与溯源校验，并调整了预算与重试逻辑；更严格的证据要求会提高阻断概率，从而降低覆盖率。由于两轮各只运行一次且温度未固定，这一差异包含流程改动与运行波动两部分，不能单独归因于 问题分析与证据评估。

### 6.6 局限补充

两次运行都是单轮、温度未固定；证据包与结算口径未变，但流程代码在两次运行之间变化，因此两组数字只能作为"合并前后"的观察，不是严格的对照实验。若要将结论归因到 问题分析与证据评估，需要在固定温度下对同一代码重复运行，并分别比较覆盖率与分数。
