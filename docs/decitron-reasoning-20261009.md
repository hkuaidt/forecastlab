# Decitron 推演表达与原文取证改进

参考方式：直接查看用户 Edge 浏览器中提供的 Decitron 实际案例，检查画布、角色画像、来源依据和推演总结。仅参考结构，不复用其案例事实、日期或概率。

## 实现范围

- 保持现有 API 和 schema、四主体上限、两轮行动以及概率校验。
- 提示词组织为：可引用的已知事实 → Round 0 当前局势 → 主体的现实行动 → 同一组变量的变化 → 条件情景及相对概率理由。
- 区分来源原文、保守事实释义与模型的条件解释；未来行动和状态不冒充既成事实。
- 检索关注任务、记录和决策约束；正文选段保留检索词与已解决澄清中的具体术语。
- Brave 入选来源在保存前尝试抓取 HTML 或纯文本正文，复用既有快照、hash、段落和引用位置。失败时保留搜索摘要及原因。
- 正文抓取最多 10 页、并发 3、单页 6 秒、批次 20 秒，限制响应大小和重定向，逐跳核验公共地址，固定连接 IP 并保留 TLS 域名校验。
- 画布展示真实证据发现及引句、初始变量、主体行动及影响、情景条件与理由。通用资料限制收拢到可展开入口，具体矛盾仍可见。
- 初始角色卡只展示当前目标、资源和约束，不混入后续轮次行动。点击原文读取完整保存文本，而非 12,000 字的摘要字段。
