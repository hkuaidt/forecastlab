# 适用范围与限制

ForecastLab 是课程研究系统。自动化测试验证软件行为，固定教学数据用于流程检查；真实模型与检索的评测范围、样本量和结果见 [实验索引](../experiment/README.md)。已有实验不能证明概率已校准，也不能证明多阶段推演优于使用相同证据的单次模型预测。

## 证据与时间边界

- 哈希、段落定位和逐字引用校验能证明引用与保存的原文匹配，不能单独证明来源可信或推理成立。语义支持关系仍需人工核查。
- 搜索摘要与网页正文分别标注。正文和模型上下文有长度上限，轻量相关段落选择可能漏掉间接相关内容。
- 来源组只记录明确或疑似转载关系，不代表已经验证来源相互独立。
- 时间未知保持未知。今天取得的网页即使声称早已发布，也不能自动证明预测截点之前的网页内容相同；严格回测需要可核验的冻结材料。

## 运行与部署

当前采用单用户、单进程模型，没有账户认证、租户隔离或分布式队列。对外使用前需配置认证网关并保护 `.env`、运行数据库和证据快照。

模型调用数与活动耗时受预算约束；用户等待确认的时间不计入模型活动时间。进程异常退出或服务方未返回用量时，真实 token 和费用可能无法完整重建，不把未知值当成精确账单。联网失败后的恢复行为以保存的检索状态为准，重新取证应创建新运行。

## 评测解释

- 固定响应不证明模型理解能力，少量样本不代表一般化质量。
- 人工标签、模拟审阅者、同模型判定和独立模型判定必须分别报告。
- 真实模型评测应保留失败与未执行样本，并说明信息截点、训练数据泄漏、模型版本和费用。
- 原始结果中保留当时的模型、提示版本和路径，不能将它们解释成当前版本重新运行的结果。
