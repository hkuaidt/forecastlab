# LLM 辅助使用与贡献说明

项目开发中使用 ChatGPT 辅助代码分析、实现、测试、故障排查和文档编写。原项目的后端、前端和推演框架，以及组员的实验成果，应按实际提交和工作记录归属，不能记为工具或个人独立完成。

问题定义与证据评估在项目提案中由 Zhang Kaiqi、Wang Kongtao、Tang Naisheng 共同负责；具体个人贡献由小组根据实际工作确认。

固定教学数据与模型响应用于软件验证，真实模型评测及人工审核结果分别保存在 `experiment/`，以各实验报告的执行方式和限制为准。小组仍需阅读代码、复跑测试、核查来源与结论，并按课程要求如实说明工具使用情况。
